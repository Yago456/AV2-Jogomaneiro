# Calabouço dos Números

Jogo web educativo de matemática para estudantes do 6º ano do Ensino Fundamental.

## Como executar
1. Baixe os três arquivos `index.html`, `style.css` e `script.js`.
2. Deixe os três arquivos na mesma pasta.
3. Abra `index.html` no navegador.

## Publicar gratuitamente com GitHub Pages
1. Crie um repositório público no GitHub, por exemplo `calcadouro-dos-numeros`.
2. Envie os três arquivos para a raiz do repositório.
3. Acesse **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch `main` e a pasta `/(root)`, depois clique em **Save**.
6. Aguarde a publicação. O endereço ficará parecido com `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.

## Conteúdos matemáticos
- Adição e subtração com números naturais.
- Multiplicação e divisão exata.
- Dobro e metade.
- Estratégia, leitura e cálculo mental.

## Mecânicas
- 10 salas com perguntas geradas aleatoriamente.
- 3 vidas por partida.
- 10 estrelas por resposta correta.
- Feedback imediato e tela de resultado.
- Botão para jogar novamente.

## Tecnologias
HTML5, CSS3 e JavaScript puro (sem bibliotecas obrigatórias).

## Observações
O jogo utiliza uma fonte externa do Google Fonts quando há conexão com a internet; se não houver, usa fontes alternativas instaladas no dispositivo.
